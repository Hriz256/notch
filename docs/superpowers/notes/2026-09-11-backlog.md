# Backlog after sub-project 1 (Island Core + Music)

Collected from the per-task reviews and the final whole-branch review. Nothing here blocks
sub-project 2; items are grouped by module, most valuable first.

## Should do soon

- **AppleScript fallback violates the idle rule.** `NowPlayingClient/AppleScriptNowPlayingSource.swift`
  polls every 2 s (plus up to two `player state` probes per poll) whenever Spotify or Music is
  *running*, even paused with a bare notch. Only reachable when the MediaRemote helper is
  unavailable. Fix: skip the poll when nothing is playing and no presentation is live.
- **`PrivateSpace.init?` fails open.** Non-zero `setLevel`/`show` results are logged but the
  initializer still succeeds; an invisible island is worse than a sliding one. Return nil instead.
- **Stale hover after a geometry rebuild.** `SurfaceController.buildWindow` replaces the
  `HoverMonitor` without telling the presenter the pointer left; call `presenter.setHovering(false)`.
- **`toggleHoverPromotion()` ignores eligibility.** Clicking the bare notch latches promotion;
  guard with `isHoverEligible || isHoverPromoted` in `IslandPresenter`.
- **`MusicFeature.deactivate()` fires `coordinator.stop()` and forgets it.** With the
  "Reload helper" menu item this race is now user-reachable; await the stop before re-activating.
- **Hover/click rect excludes the drawn flares** (`layout.size.width` vs `+ 2 * topRadius`).
  Decide whether the flares should be interactive.

## IslandCore

- `TransitionChoreographer.current()` is read once; observe
  `NSWorkspace.didChangeAccessibilityDisplayOptions` to react to Reduce Motion live.
- `ScreenMetrics.current()` picks the first screen with a top inset rather than the built-in one.
- `NotchGeometry` mixes aux-area x/width with `safeAreaTop` height; untested for non-origin frames.
- `IslandLayout.resolve` ignores the `PresentationID` inside the state; `topRadius` and the
  height clamp are untested; no public memberwise init.
- `NotchShape`: `b` lacks `max(0, …)`; single-letter names; `.contentShape` is the full rect.
- `SurfaceView`: redundant frame on the expanded branch; `.id` via string reflection.
- `IslandPresenter`: `setHovering(true)` not idempotent; `update` never re-arms TTL;
  present-of-existing-id semantics undocumented; `TaskClock` task not cancelled on dealloc;
  hover suppression outlives the presentation.
- `FeatureRegistry.register` twice with the same id is unguarded.
- `SurfaceController`: `resolve()` per mouse move, unused `hostingView`, duplicate `setFrame`,
  no-notch path keeps the monitor and window.
- `PrivateSpace`: hide/destroy optional-symbol conflation; destroy before `orderOut`;
  `PrivateSpaceTests` fails instead of skipping without SkyLight; `setVisible` unused (kept for a
  future "hide in fullscreen" option). Space is not destroyed on SIGKILL — unverified whether
  WindowServer reaps it.

## NowPlaying (shared / client / helper)

- Shared: nil-`artworkID` bytes reset `lastSentArtworkID`; `PlaybackProgressTracker` returns 0
  for NaN elapsed on an unsanitized snapshot; whitespace-only title counts as a track.
- Client: source comparison by name (use identity); double `.unavailable` → double activate;
  `checkSilence` does not re-check after the probe; `stop()` is not terminal; old connection not
  invalidated on manual restart; `invalidate()` under lock; retries not reset after max;
  commands dropped silently when disconnected; concurrent `poll()` from `send`; newline in
  metadata shifts fields; `isRunning` check and connection swap not under one lock;
  `errorNumber 0` sentinel shared; `seek` interpolates a `Double`; Music `missing value`
  duration fails the whole script; no test for commands after fallback.
- Helper: `getIsPlaying` now used; `Command.stop` unused; `dlclose` comment; doubly-weak closure;
  no runtime test harness for the XPC service.
- Optimistic play/pause: a stale rate-0 snapshot arriving after an optimistic play flips the UI
  back for up to ~1 s; consider a short grace window.
